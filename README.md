# Minder

[minder.ge](https://minder.ge) — Notion-ის სტილის პირადი სამუშაო სივრცე, რომლის ბირთვი ფინანსური ცხრილია. ერთ ვებ-აპში ერთიანდება ხარჯების აღრიცხვა, მოქნილი Excel-ის მსგავსი ცხრილები, ჩეკლისტ-ნოუთები, კვირის განრიგი და ინგლისური სიტყვების ლექსიკონი. ინტერფეისი ქართულია, მუშაობს როგორც PWA (ტელეფონზე დასაინსტალირებელი), სწრაფია და მინიმალისტურია.

---

## 1. იდეა

ყოველთვიური ხარჯების აღრიცხვა ჩვეულებრივ Excel-ში ან Notion-ში ხდება: თითო თვეზე ცალკე ფურცელი, ხელით გადატანილი განმეორებადი ხარჯები, ხელით დათვლილი ჯამები. Minder ამ პროცესს ასწორებს:

- **ერთი უწყვეტი ცხრილი, თვე მხოლოდ ფილტრია.** განმეორებადი ხარჯები (ქირა, ინტერნეტი, სესხი) ახალ თვეში ავტომატურად ჩნდება როგორც „მოლოდინში“, დუბლირების გარეშე.
- **სტატუსი თანხიდან გამომდინარეობს, არა პირიქით.** `გადასახდელი` vs `გადახდილი` → `გადახდილი / ნაწილობრივ / მოლოდინში` ითვლება ავტომატურად; ბიუჯეტის ნაშთი ყოველთვის სწორია.
- **Excel-ის სიჩქარე ბრაუზერში.** Inline რედაქტირება, Enter = ქვემოთ, Tab = მარჯვნივ, Esc = გაუქმება, Space = სტატუსის ციკლი, ოპტიმისტური განახლება სერვერის ლოდინის გარეშე.
- **მომხმარებელი თავად აწყობს სვეტებს.** რიცხვი, ტექსტი, არჩევანი, სტატუსი, თარიღი, ფორმულა — ყველაფერი custom column-ია, მკაცრი სქემის გარეშე.
- **ერთი სივრცე ყოველდღიური ცხოვრებისთვის.** იგივე აპი ინახავს სავაჭრო სიებს, კვირის რუტინას და სასწავლო სიტყვებს — ფინანსების გვერდით, ცალკე აპების გარეშე.

## 2. ფუნქციონალი

### 2.1 ცხრილები (Sheets)

ცხრილი აპის ძირითადი ერთეულია. სამი ტიპი:

| ტიპი | დანიშნულება |
| --- | --- |
| `monthly_expenses` | ყოველთვიური ხარჯები — თვეების ნავიგაცია, განმეორებადი რიგების ავტომატური გადატანა (rollover) ახალ თვეში. |
| `table` | თავისუფალი ცხრილი თვეების ჭრილში (იგივე მექანიკა, უფრო ზოგადი დანიშნულება). |
| `calculator` | ერთჯერადი ცხრილი ჯამებით — თვეების გარეშე. |

**სვეტები (`custom_columns`)**

- ტიპები: `number`, `text`, `select`, `status`, `date`, `formula`.
- `formula` — უსაფრთხო გამომთვლელი (`=qty*price`, `={amount}-{paid}`): რიცხვები, სვეტების slug-ები, `+ - * /`, ფრჩხილები. LLM და `eval` არ გამოიყენება.
- `summable` — სვეტის ჯამი ქვედა სტრიქონში (`Σ`).
- `role` — გადახდის როლი: `payable` (გადასახდელი), `paid` (გადახდილი), `remaining` (დარჩენილი). როგორც კი `payable` და `paid` ორივე მინიჭებულია, ჩაირთვება **გადახდის რეჟიმი**:
  - სტატუსი თითო რიგზე ავტომატურად: გადახდილი / ნაწილობრივ / მოლოდინში;
  - ზედა პანელზე **ბიუჯეტი** (ინახება `sheets.budget`), გადახდილი, დარჩ. გადასახდელი, დარჩა ბიუჯეტი;
  - `remaining` სვეტი ითვლის `გადასახდელი − გადახდილი`-ს.
- სვეტების გადარქმევა, გადაადგილება, წაშლა, არჩევანების რედაქტირება — „რედაქტირება“ რეჟიმიდან.

**რიგები (`sheet_rows`)**

- მნიშვნელობები JSONB-ში (`values`), სქემა ცხრილის სვეტებიდან მოდის.
- ბოლო ცარიელი რიგი ყოველთვის ავტომატურად არსებობს — ახალი ჩანაწერი დაწყება უბრალოდ წერით.
- სორტირება ნებისმიერი სვეტით, შენიშვნის ველი თითო რიგზე.
- **შეხსენებები**: რიგზე თარიღი/დრო, სერვერი ყოველ წუთს ამოწმებს და ელფოსტაზე აგზავნის (`SendDueReminders`).
- **Rollover**: ახალი თვის გახსნისას წინა თვის რიგები იდემპოტენტურად გადმოდის (template + year_month გასაღებით).

**ექსპორტი**: Excel (`xlsx`) და PDF ბრაუზერიდან, ჯამებით.

### 2.2 ლეჯერი და Quick Entry (Cmd+K)

კლასიკური ფინანსური ლეჯერი `transactions` ცხრილზე:

- ტიპი: `expense | income | transfer`; სტატუსი `paid | pending | partial` ყოველთვის `amount_paid` vs `amount`-დან.
- ანგარიშები `opening_balance`-ით — ბალანსი ლეჯერის აქტივობიდან გამოითვლება.
- კატეგორიები, განმეორებადი შაბლონები (`recurring_templates`), თვის შენიშვნები.
- **Quick Entry**: `⌘K` → თავისუფალი ტექსტი („ინტერნეტი 60 გადახდილი TBC“) → დეტერმინისტული პარსერი (regex + fuzzy match) ამოიცნობს თანხას, ვალუტას, სტატუსს, ანგარიშს, კატეგორიას → preview ჩიპები → Enter ინახავს. ქართული და ინგლისური საკვანძო სიტყვები.

### 2.3 ნოუთები (Notes)

- ჩეკლისტები ორი რეჟიმით: `checkbox` (მრავალი მონიშვნა) და `radio` (ერთი არჩევანი).
- ელემენტების დამატება/გადაადგილება/მონიშვნა inline.
- პაროლით დაცვა (Pro).

### 2.4 კვირის განრიგი (Schedule)

- კვირის ბადე (ორშ–კვ), ბლოკები დაწყება/დასრულების დროით.
- კატეგორიები: `sleep | spiritual | physical | family | work | reading | leisure`.
- შაბლონები (`schedule_templates`) ტიპიური დღის სწრაფად შესავსებად.

### 2.5 ლექსიკონი (Dictionary)

- ინგლისური სიტყვა ↔ ქართული თარგმანი, მაგალითი ორივე ენაზე.
- კატეგორიებად დაჯგუფება, სასწავლო რეჟიმი სვეტების დამალვით.

### 2.6 გაზიარება და წვდომა

- **ResourceShare**: ცხრილის ან ნოუთის გაზიარება ელფოსტაზე მოწვევით (`/invite/{token}`).
- როლები: `moderator` (რედაქტირება) და `viewer` (მხოლოდ ნახვა).
- **პაროლით დაცვა**: ცხრილი/ნოუთი იკეტება ცალკე პაროლით; სესიაში განბლოკვა.
- ყველა მონაცემი `user_id`-ით იზოლირებული; Policies ყოველ რესურსზე.

### 2.7 ანგარიში, გეგმები, ადმინი

- რეგისტრაცია/შესვლა ელფოსტით **ან Google / Facebook-ით** (Laravel Socialite). სოციალური ანგარიში იმავე ელფოსტის იუზერს ავტომატურად ებმის; პაროლის დაყენება პროფილიდან მოგვიანებითაც შეიძლება.
- პროფილი: სახელი, ელფოსტა, პაროლი.
- გეგმები (`config/plans.php`):

| | უფასო | Pro |
| --- | --- | --- |
| ცხრილები | 5 | ∞ |
| ნოუთები | 15 | ∞ |
| ლექსიკონი | — | ✓ |
| გაზიარება | — | ✓ |
| პაროლით დაცვა | — | ✓ |

- პლატფორმის ადმინი: მომხმარებლების სია, გეგმის შეცვლა, დაბლოკვა, სტატისტიკა.

### 2.8 UX

- ღამის/დღის თემა, Georgian UI copy.
- PWA: offline shell, „დააინსტალირე“ ღილაკი, service worker.
- კლავიატურა: Enter ↓, Tab →, Esc გაუქმება, Space სტატუსის ციკლი, ⌘K სწრაფი ჩანაწერი.
- ოპტიმისტური UI ყველა უჯრედის რედაქტირებაზე.

## 3. ტექნიკური სტეკი

### Backend — `backend/`

| კომპონენტი | არჩევანი |
| --- | --- |
| ენა / ფრეიმვორკი | PHP 8.3, Laravel 11 |
| ბაზა | PostgreSQL (JSONB `sheet_rows.values`, `transactions.custom_fields`) |
| ავტორიზაცია | Laravel Sanctum — SPA cookie auth (`statefulApi`), Laravel Socialite (Google, Facebook) |
| სესია / ქეში / რიგი | database driver; `QUEUE_CONNECTION=sync`; Redis არ არის v1-ში |
| მეილი | SMTP (შეხსენებები) |
| არქიტექტურა | თხელი კონტროლერები → `Actions/` (`RolloverSheetRows`, `ApplyRecurringTemplate`, `ResolveSocialUser`…) და `Services/` (`QuickEntryParser`); API Resources; Policies `user_id`-ით |
| Scheduler | `SendDueReminders` ყოველ წუთს (`schedule:run` cron) |

ძირითადი ცხრილები: `users`, `social_accounts`, `sheets`, `custom_columns`, `sheet_rows`, `transactions`, `accounts`, `categories`, `recurring_templates`, `month_notes`, `notes`, `note_items`, `schedule_blocks`, `schedule_templates`, `words`, `word_categories`, `resource_shares`.

### Frontend — `frontend/`

| კომპონენტი | არჩევანი |
| --- | --- |
| ენა / ბილდი | TypeScript (strict, `any` აკრძალულია), Vite |
| UI | React 19, TailwindCSS 4, Lucide icons, `cmdk` (⌘K) |
| მონაცემები | TanStack Query v5 (ოპტიმისტური მუტაციები), TanStack Table |
| ექსპორტი | `xlsx`, ბრაუზერის print → PDF |
| PWA | `vite-plugin-pwa` |
| ტიპები | ერთი წყარო — `src/lib/types.ts` |

### სტრუქტურა

```
backend/   Laravel 11 API  (http://localhost:8000)
frontend/  Vite React SPA  (http://localhost:5173, VITE_API_URL → backend)
```

### ლოკალური გაშვება

```bash
# backend
cd backend && cp .env.example .env && composer install
php artisan key:generate && php artisan migrate && php artisan serve

# frontend
cd frontend && npm install && npm run dev
```

OAuth-ისთვის `.env`-ში `GOOGLE_CLIENT_ID/SECRET`, `FACEBOOK_CLIENT_ID/SECRET`; redirect URI — `{APP_URL}/auth/{provider}/callback`.

### Production

ერთი დომენი: Nginx აწვდის `frontend/dist`-ს, `/api`, `/sanctum`, `/auth`, `/up` → PHP-FPM (Laravel). PostgreSQL იმავე სერვერზე, `schedule:run` cron-ით, ყოველდღიური `pg_dump` backup. რეკომენდებული VPS: 2 vCPU / 8 GB (მაგ. Hostinger KVM 2) — სხვა პროექტებთან ერთადაც საკმარისია.

## 4. პრინციპები განვითარებისთვის

1. ახალი ფუნქცია — `transactions`/`sheets` + Action-ების გაფართოებით, არა პარალელური ცხრილებით.
2. ⌘K → preview → Enter ფლოუ უცვლელი რჩება.
3. ბადის კლავიატურის ქცევა (Enter/Tab/Esc/Space) უცვლელი რჩება.
4. ქართული UI, მუქი მინიმალისტური სტილი, სიჩქარე პირველ ადგილზე.
